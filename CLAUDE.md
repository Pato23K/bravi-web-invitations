\# BRAVI — Web Invitaciones (Project Context &amp; Rules) ## 📌 Visión del Proyecto BRAVI es una plataforma web modular de invitaciones digitales interactivas para eventos [1]. El desarrollo sigue una arquitectura de Plantilla Maestra reutilizable y escalable, estructurada en 4 niveles de suscripción: Express, Esencial, Signature y Elite [1, 2]. ## 🛠️ Tech Stack &amp; Herramientas - \*\*Framework:\*\* Next.js (App Router) [1] - \*\*Lenguaje:\*\* TypeScript (modo estricto) [1] - \*\*Estilos:\*\* Tailwind CSS + Variables CSS en globals.css para temas dinámicos [1, 4] - \*\*Control de Versiones:\*\* Git &amp; GitHub [1] ## 📱 Reglas de Diseño y Arquitectura ### 1\. Mobile-First Estricto - Target Principal: Optimizado estrictamente para viewports móviles de 390px a 430px [2]. - Todos los layouts, botones e interacciones deben validarse primero en resoluciones de smartphones [2]. ### 2\. Estructura Modular por Planes (Herencia de Componentes) - \*\*Plan Express (Fase 1):\*\* Hero Video 100vh (bucle continuo), Cuenta regresiva en JS y Botón RSVP con deep link a WhatsApp [2-4]. - \*\*Plan Esencial (Fase 2):\*\* Hereda Express + Deep links nativos a Google Maps/Waze, Mesa de regalos básica y variables CSS para cambio de paleta de colores [3-5]. - \*\*Plan Signature (Fase 3):\*\* Hereda Esencial + Reproductor de audio global, Carrusel táctil de fotos, Dress Code y Copiado inteligente de CLABE mediante Clipboard API [3, 5, 6]. - \*\*Plan Elite (Fase 4):\*\* Hereda Signature + Itinerario en línea de tiempo vertical y tarjetas desplazables con recomendaciones de hospedaje [3, 6]. ### 3\. Restricciones Técnicas Obligatorias - \*\*Hero Video:\*\* Debe ocupar 100vh con atributos obligatorios \`autoPlay\`, \`muted\`, \`loop\`, \`playsInline\` y una capa overlay oscura para garantizar el contraste de los textos [2]. - \*\*Audio Global:\*\* Debido al bloqueo de autoplay con sonido en navegadores móviles, el audio debe iniciarse mediante un botón flotante de reproducción o con el primer tap del usuario [5]. - \*\*Deep Links Móviles:\*\* Los botones de ubicación y RSVP deben activar las aplicaciones nativas (WhatsApp, Waze, Google Maps) mediante URLs de esquemas nativos [4]. - \*\*Copiado de CLABE:\*\* Implementar la API nativa \`navigator.clipboard.writeText\` acompañada de un aviso de confirmación (Toast) [6]. ## 💬 Convenciones de Código - Utilizar React Server Components (RSC) por defecto; limitar \`'use client'\` a componentes interactivos con estado o eventos del navegador (Audio Player, Contador, Copiar CLABE, Carrusel). - Definir interfaces de TypeScript explícitas para las props de cada componente. - Mapear la paleta de colores a variables CSS (\`--primary\`, \`--accent\`, \`--background\`) para permitir la tematización por evento [4].
